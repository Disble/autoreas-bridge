Notification Center

/notifications

Persist before you interrupt

A toast the user cannot find again is worse than no toast. The record is committed first, so anything that flashed on screen is still there afterwards.

Storage failure never eats the message

Producers discard the notifier's error by design. So a failed write still projects — it just loses its history entry, and says so in the log.

A notification carries actions, it does not define them

It holds a token addressing an operation the app registered elsewhere, resolved when pressed — never a stored function, and never a button invented for one event.
