The record stores references, never pictures

A row carries { type, id }. The cover is resolved at render through getAnimeCover, which the Today screen already calls and already caches per session — falling back to the same night-bridge art. No image ever enters SQLite.

Rows are bounded, and the boring ones collapse

A run can touch fifty anime. Show what needs attention — failed, blocked, stopped — then fold the rest into one line. A notification that lists everything is a log, and we already have one of those.

Where the four earlier blocks went — none survive as their own component

segments → deleted. The count moved into the body sentence, which already said it.
reasons → became the detail line of a row — “Missing source” now sits under the anime it blocks.
links → became row actions — each hoster is a copy intent on the row for that episode.
entities → became the row itself — it was always a list of anime, only without cover, status or action.

Three of the four were never separate ideas. They were parts of a row I had not drawn yet.
