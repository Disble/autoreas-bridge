## Specs

- S1 Header: page title "Catalog" with a primary "Create" button (plus icon, accessible name "Create an anime") that navigates to `ANIME_CREATE_ROUTE`. The old subtitle "Browse the synchronized anime inventory" is removed. The Create button, toolbar and result line are hidden when the catalog has no anime at all (the empty state already offers Create); the "Catalog" title stays (mockup `index.html:807-811`). The result line is also hidden while loading and on a failed request.
- S2 Toolbar, one row that wraps: search field "Search by name…" (search icon, clear button only while there is text, Esc clears), "Filters" secondary button with an active-count badge, Sort select, Grid/List view toggle (icon-only, labels "Grid view" / "List view").
- S3 Filters popover (HeroUI Popover), title "Filters" with a close button. Groups of selectable tags: "Status" (All, Viendo, Finalizado, En pausa, No me gusto) and "Type" (All, Anime (TV), Película, Especial, OVA) are multi-select and match ANY picked value (L9: "yo puedo querer buscar anime del type TV y movies al mismo tiempo"); "All" is shown selected while a group is empty and picking it clears the group, "Genres" with hint "Shows anime that have every selected genre." (multi-select, every selected genre must match). Footer: "Reset filters" (tertiary) and primary "Show N anime" that closes the popover. Selected tags show a check icon. The old Active, Day and Download gap filters are removed (user, mockup v2: "El filtro de descarga no lo tomes en cuenta").
- S4 Sort options: "Name A–Z" (default), "Name Z–A", "Status" (order Viendo, Finalizado, En pausa, No me gusto, then name), "Type" (kind order, then name), "Last watched" and "Date created" (L9, from Legacy "Últ Cap Visto" / "Fecha Creación": newest first, undated records last, ties by name). Name comparison is numeric-aware and case-insensitive. No year sorts (decision L2).
- S5 Result line: "Showing all **N**" when nothing is hidden, otherwise "Showing **n** of N"; one removable chip per active filter ("Status: Viendo", "Type: OVA", "Genre: Drama"); a tertiary "Clear search and filters" button while any search or filter is active.
- S6 Grid view (default): cover cards in an auto-fill grid (min column 152px), cover cropped to 230:326, title clamped to two lines, meta line with the type label only (no year, L2), `estado` chip below (soft, sm: Viendo accent, Finalizado success, No me gusto danger, En pausa warning). Card hover lifts the cover. The whole card links to `/catalog/detail/:id`.
- S7 List view: one surface card holding rows separated by a divider: 40px cover thumbnail, title (truncated), meta "Type · Genre, Genre" (no year, L2), `estado` chip, trailing chevron. The row links to the detail route.
- S8 Covers load through the existing `getAnimeCover` binding, only for rows inside the progressive window and only when `hasCover` is true; a loading cover shows a skeleton of the same shape; a missing or failing cover shows the approved Airis "No Cover" poster (`no-cover.webp`, mockup v23: "Nos quedamos con este cover como el aprobado para placeholder") cropped like a real cover, with a "No cover" label on cards (hidden on list thumbnails). Scope: Catalog only; other screens keep `CoverPlaceholderScene` until asked.
- S9 Loading, empty and failure stay exclusive (CLAUDE.md contract): loading is a shape-matching skeleton for the active view (cover cards or list rows) inside `role="status"`; actual-empty uses `AirisEmptyState` with the catalog mascot and "Create an anime"; criteria-empty uses the filtered kind with "Clear search and filters"; failure uses the existing danger `Alert` "Catalog unavailable".
- S10 Progressive rendering (ADR-012) is kept for both views: an initial batch, growing as the PAGE nears its bottom (no inner scroll pane, no own max-width: Catalog fills the app container like every other screen, L8), with a DOM-count test proving one batch. The list footer reads "End of catalog" when everything is shown.
- S11 Returning from an anime detail to Catalog keeps the search, filters, sort and view the user had (session memory, not persisted to disk).
