# Async-state residuals

Objective: close the three high-priority residuals of the async-state standard (ADR-032) found by the 2026-11-16 transversal audit (`design/async-state-audit-20261116/`, findings A1-A3). Branch `feat/async-state-residuals` from `dev` 9c7444c9, units in sequence, one commit each, one local merge into `dev` at the end. Delivery: single branch, no intermediate merges. Runners: `go test`, Bun/Vitest.

## Specs

- S1 (Unit 2, A2) "Comprobar y completar la invalidación de consultas anime." Acceptance: "Escrituras locales y eventos externos refrescan las vistas afectadas sin sobrescribir borradores del Editor." `anime.changed` today invalidates only `episodesKeys.all` (`bridge-runtime.constants.ts:126`); the anime list, detail and watch-history reads (`animeKeys`) stay stale while mounted. The Editor's `animeEditorKeys` prefix stays out. Covers stay out: one anime change would refetch every cover on screen (decision, see L2).
- S2 (Unit 1, A1) "Eliminar el éxito aparente en los dos comandos de descarga de Season." Acceptance: "Readiness y resultado real llegan al consumidor; los casos no disponibles nunca confirman inicio; no hay reintento automático de mutaciones." `TriggerSeasonDownloads` answers `"ok"` unconditionally (`app_season_availability.go:211-214`); `DownloadSeasonAnimes` answers a status string. Both answer through the `downloads` handle and return an error, like `TriggerDownloadCheck`/`TriggerAnimeDownload`; the Daily Board shows the refusal instead of swallowing it.
- S3 (Unit 3, A3) "Migrar el ciclo completo de Keymap." Acceptance: "Personalización vacía válida, carga pendiente y error son distinguibles; rebind y reset conservan su semántica." `GetKeymap` answers `""` for no store, a failed read and no customization alike (`app_preferences.go:147-158`). Both bindings answer through the `settings` handle with an error; the frontend reads them through the `SettingsSource` port and the keymap load waits for the `settings` module before reading (the reason it was deferred, `docs/architecture/contexts/settings/overview.md` Known drift).
- S4 Closure: `tools/checkarchitecture/baseline.yaml` loses the 8 Go entries (4 bindings); the frontend baseline loses the keyboard entries this migration resolves; `docs/architecture` pages of the touched modules (cross-cutting async-state, settings, season, downloads as touched) match the code.
- S5 Existing behavior stays: Today's `anime.changed` refresh, Editor drafts, the Daily Board send flow, Ver hoy selection semantics, keymap rebind/reset/shadow warning, backup import keymap reload.

- S6 (Unit 4, A4) "Migrar por consumidor: readiness, errores, lectura o mutación y representación del estado juntos. Quitar cada entrada resuelta del baseline, sin reemplazar un fallback por otro." Proof: "Binding ausente, módulo starting, módulo failed, error de lectura y resultado vacío real deben producir estados distintos cuando el contrato los distingue." Every `migrate` entry of L9 reads through a `BRIDGE_*_SOURCE` port; defaults D1-D4, D6 of L9 apply.
- S7 (Unit 4, A5) "Clasificar cada excepción: migrar, conservar con motivo o revisar. Aclarar quién posee la frescura del dato y quién posee el estado de UI; preservar debounce y paginación." Proof: "Ninguna eliminación rompe progreso de matching, navegación, toasts o archivo paginado." D5 (owner, 2026-11-17): "Separate list" — a gate exception list, each entry with a written reason, separate from the baseline; the baseline holds only debt. Exceptions: #26, #31, #34, #35, #53-55 (L9) plus #4 and #5 (debounced refreshes the registry cannot express).
- S8 (Unit 5, A6) "Reconciliar documentos con los símbolos y consumidores actuales dentro de las unidades que los migran; no corregir solo el número." Proof: "Cada método citado como pendiente existe en el inventario residual; cada método eliminado de la lista tiene evidencia de su ruta actual."
- S9 (Unit 5, A7) "Cerrar por requisito: residual clasificado, comprobación de comportamiento y documentos reconciliados." Frontend baseline ends at 0 entries; dead legacy adapter members (season `invokeSeasonRead` readers, `searchProviders`, preferences source, unused `bridgeRuntimeSource` members) are removed once nothing uses them.
