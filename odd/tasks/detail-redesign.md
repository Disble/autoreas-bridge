## Specs

- **S1 Toolbar (P2, P3).** A card toolbar: ghost icon-only Back button on the left (aria "Back", tooltip "Back"); actions on the right as neutral icon-only buttons with tooltips, in this order: Repeat (only when estado > 0), Restore (only when inactive), Edit (always, always last, tooltip "Edit anime"). aria-labels `Repeat <name>` / `Restore <name>` / `Edit <name>`. While a mutation runs every action is disabled, Edit included ("While a mutation runs every action is disabled (isDisabled={isMutating}); Confirm in the dialog shows a spinner (isPending)."). Back returns to the previous screen (`navigate(-1)`), whichever it was; its existing no-history fallback stays unchanged (see L4).
- **S2 Cover (P1).** A full-frame 5:7 cover replaces the 84px round avatar, alt `Cover of <name>`. Without a cover, the approved Airis no-cover poster (`frontend/src/assets/covers/no-cover.webp`, as the Catalog's `CatalogCoverSlot`) fills the frame: "The approved Airis "No Cover" poster fills the cover frame; the "No cover" pill shows only at full size." The skeleton mirrors the new shape.
- **S3 Title and chips (P4).** The anime name is the page `h1`. Under it, one spacing-scale step away (`gap-2`, never arbitrary px), so the chips never touch the title: the type alone as subtitle (Anime (TV) / Película / Especial / OVA), then the estado chip (Viendo=accent, Finalizado=success, No me gusto=danger, En pausa=warning), then Active (success) or Inactive (danger). Chips soft, size sm.
- **S4 Progress (P5).** One progress line replaces the three stat tiles: `N of M episodes` (or `N episodes · No total episodes data` without a total) and on the right `Duration · N min` (or `No episode duration data`), then a progress bar (aria "Episodes watched") only when a total exists.
- **S5 General data (P4, P6).** A "General data" card beside the cover, above the fold, fields in this order: Folder (full width, with a ghost icon button aria "Copy folder path", tooltip "Copy path"), Page (full width, a link that opens in the system default browser through the existing `openAnimePage` bridge binding, like every other URL in the app; no `href`/`target="_blank"`, which opens an internal WebView window; failure toasts "Could not open the page", success is silent), Studios, Origin, First watched, Last episode watched, Creation date, Genres (chips, or "No genres listed"). Missing values read "Unknown"; dates long format ("October 20, 2026"). Copy uses the existing `copyAnimeFolder` binding and toasts "Folder path copied" or "Could not copy the folder path".
- **S6 Responsive.** Container ≥700px: cover 280px column stretched to full height, General data in 3 columns. Below 700px: small cover thumbnail, General data full width in 2 columns, no "No cover" pill. Below 420px: 1 column.
- **S7 Watch history.** Watch history moves out into its own card below the main card; its content is unchanged.
- **S8 States.** The mockup states hold: Default (Repeat + Edit), No cover, Inactive (Repeat, Restore, Edit; Inactive chip danger), Watching (Edit only), Applying (all disabled, Confirm pending). Confirm dialog copy stays as today (`Repeat <name>?` / "This starts a new watch cycle." etc.).
- **S9 No legacy.** The old avatar header, text "Edit anime" button, stat tiles and old field order are deleted with their tests, not kept beside the new layout. Tests are updated/extended, not added, except where a behavior is genuinely new (copy folder, Edit disabled while mutating).

Out of scope: the mockup's proposals band, "Preview state" control and "Show proposals" switch (prototype chrome). No Go or contract change is needed: every field and action exists today.
